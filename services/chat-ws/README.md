# Microservicio chat-ws (Andalucía Mesh)

Servicio público de solo lectura en `wss://${PROJECT_DOMAIN}/ws/chat` para suscribirse en directo a los mensajes de texto de difusión emitidos por la malla en los canales admitidos (`ALLOWED_CHANNELS`).

Documentación canónica y especificación completa: [`docs/info/chat-ws/README.md`](../../docs/info/chat-ws/README.md).
