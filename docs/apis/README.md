# Documentación Oficial Destilada de APIs de Terceros

Este directorio alberga la documentación oficial de APIs externas que consume el proyecto, destilada y comprobada con peticiones reales.

## Estructura para cada API (`docs/apis/<api>/`)

Cada API de terceros se documenta bajo su propio directorio con la siguiente estructura canónica:
- `README.md`: Fuentes oficiales, fecha de descarga y fecha de verificación real.
- `00-fundamentos.md`: Conceptos clave, autenticación y convenciones de la API.
- `ERRATAS.md`: Errores o discrepancias encontradas en la documentación oficial respecto al comportamiento real.
- `LIMITACIONES.md`: Cuotas, límites de tasa, restricciones y casos no soportados.
- `<dominio>.md`: Documentación destilada por dominio funcional específico.
- `src/`: Fuentes originales descargadas (solo consulta de referencia; no se editan ni se leen de rutina).
